Uso diario: tus imágenes a un clic

Guarda las imágenes que mandas seguido (logo, promociones, catálogo, horario, formas de pago) y pégalas en cualquier chat sin buscarlas cada vez.

  1. Fija la extensión: haz clic en el ícono de rompecabezas 🧩 de Chrome y en el alfiler junto a Adjuntar Fotos Rápido.
  2. Haz clic en el ícono de la extensión y luego en + (o arrastra las imágenes a la ventana). Se quedan guardadas en esta computadora.
  3. Abre WhatsApp Web y entra al chat de la persona.
  4. Abre la extensión, elige el proyecto, escribe el texto si quieres que vaya debajo de la imagen y toca la imagen.
  5. Revisa la vista previa y presiona Enviar. La extensión nunca envía por ti.
Si ya tenías un mensaje escrito en el chat y no pones texto en la extensión, ese mensaje pasa a ser el texto de la imagen.

Proyectos: una galería por negocio o cliente

Si manejas varios negocios, sucursales o clientes, crea un proyecto para cada uno. Cada proyecto tiene sus propias imágenes y su propio texto de pie, así nunca mandas el logo o la promoción equivocada.

  1. En la ventana de la extensión toca + junto al nombre del proyecto y escribe el nombre (por ejemplo «Óptica», «Lavandería», «Taller»).
  2. Con ese proyecto elegido, agrega sus imágenes. El número entre paréntesis es cuántas tiene.
  3. Escribe un texto de pie si siempre mandas el mismo (por ejemplo tu horario o tus formas de pago). Se guarda en ese proyecto.
  4. Para cambiar de proyecto, elígelo en la lista. La extensión recuerda el último que usaste.

Con ✎ cambias el nombre y con 🗑 eliminas el proyecto y sus imágenes (pide confirmación). Siempre queda al menos un proyecto.

Con tu sistema (citas, pedidos, cobranza…)

Si usas un sistema web que abre WhatsApp con el mensaje ya escrito (por ejemplo, para avisar que un pedido está listo), y ese sistema es compatible con esta extensión, la imagen se adjunta sola y el mensaje sale como una imagen con su texto.

  1. Entra a tu sistema en Chrome.
  2. Haz clic en el ícono de la extensión y en Permitir para ese sitio. Esto solo se hace una vez. En sistemas que corren en la misma computadora (localhost) no hace falta.
  3. Recarga la página del sistema.
  4. Cuando el sistema abra WhatsApp Web, la imagen ya estará pegada con el texto. Solo presiona Enviar.

Puedes ver y quitar los sitios permitidos desde la ventana de la extensión.

Para desarrolladores

Cualquier página permitida por el usuario (o servida desde localhost) puede pedir que se adjunte una imagen al siguiente chat que abra en WhatsApp Web. Cada sistema manda su propia imagen, así que si tienes varios proyectos cada uno adjunta la suya sin configurar nada más.

1. Detectar la extensión

const instalada = !!document.documentElement.dataset.waImagen; // contiene la versión, p. ej. "1.1.0"

2. Dejar la imagen lista y abrir el chat

function enviarConImagen({ telefono, texto, imagen, nombre = 'imagen' }) {
  const id = crypto.randomUUID();
  return new Promise((resolve) => {
    const escuchar = (e) => {
      if (e.source !== window || e.data?.waImagen !== 'respuesta' || e.data.id !== id) return;
      removeEventListener('message', escuchar);
      if (e.data.ok) {
        window.open(`https://web.whatsapp.com/send?phone=${telefono}&text=${encodeURIComponent(texto)}`, 'whatsapp');
      }
      resolve(e.data); // { ok: true } o { ok: false, error: '...' }
    };
    addEventListener('message', escuchar);
    postMessage({ waImagen: 'enviar', id, telefono, texto, imagen, nombre }, location.origin);
  });
}

Abre la ventana dentro del mismo clic del usuario (o en menos de 5 segundos) para que Chrome no la bloquee.

Campos

CampoDescripción
telefonoNúmero con lada del país, solo dígitos (p. ej. 5215512345678). Debe ser el mismo que el phone= de la URL que abres.
imagenData URL (data:image/png;base64,…), un Blob o una URL del mismo sitio (/uploads/logo.png). PNG, JPG, GIF o WebP, máximo 5 MB.
textoTexto que irá debajo de la imagen. Usa el mismo que pones en la URL.
nombreNombre del archivo (opcional).

Cómo se comporta

  • La imagen espera como máximo 3 minutos y solo se usa si el chat que se abre es del mismo teléfono.
  • Se usa una sola vez. Cada mensaje nuevo reemplaza al anterior.
  • Si no se puede adjuntar, el mensaje se queda escrito como texto normal.
  • Nunca presiona Enviar: el usuario revisa y envía.
  • Solo funciona con WhatsApp Web en Chrome o Edge de computadora (no en la app de escritorio ni en el celular).

Privacidad

  • Las imágenes y textos se guardan solo en tu computadora (almacenamiento local de Chrome).
  • La extensión no envía datos a ningún servidor, no tiene analíticas ni publicidad y no lee tus chats.
  • Solo entra a WhatsApp Web y a los sitios que tú permitas.

Problemas comunes

Toco la imagen y dice "Abre un chat primero"

Entra a una conversación en WhatsApp Web antes de abrir la extensión.

Dice "Recarga la pestaña de WhatsApp Web"

La extensión intenta conectarse sola con la pestaña. Si aun así aparece, recarga WhatsApp Web (F5).

¿Puedo pasar mis imágenes a otra computadora?

Se guardan solo en esta computadora. En la otra, vuelve a agregarlas en el proyecto correspondiente.

Mi sistema no adjunta la imagen

Revisa que el sitio esté en Sitios permitidos y recarga la página del sistema. Si WhatsApp se abre en la app de escritorio o en otro navegador, la extensión no puede actuar; usa WhatsApp Web en Chrome.

Dejó de funcionar de un día a otro

WhatsApp cambia su página de vez en cuando. Chrome actualiza la extensión sola cuando hay una corrección; mientras tanto el mensaje se sigue abriendo como texto.

Adjuntar Fotos Rápido es una herramienta independiente y no está afiliada a WhatsApp ni a Meta.
